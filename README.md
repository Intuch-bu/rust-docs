# Rust by Example ภาษาไทย

เว็บอ่าน Rust สำหรับใช้ส่วนตัว ครอบคลุมลำดับหัวข้อของ Rust by Example พร้อมตัวอย่างในบริบทแอปและแหล่งอ้างอิงต้นฉบับ

**ยังไม่ผ่านการรับรองครบ:** เขียนเนื้อหาตามสารบัญครบ 197 หัวข้อแล้ว แต่ environment ที่สร้างงานไม่มี Rust compiler และยืนยัน Git revision ของต้นฉบับที่ดึงผ่าน web cache ไม่ได้ จึงยังไม่ถือว่าสำเร็จตามเกณฑ์พิสูจน์ทุกตัวอย่าง ดู [รายงานตรวจ](VERIFICATION.md) และ `dist/verification.json` หน้าอ่านแสดงข้อจำกัดนี้ด้วย

## เปิดอ่าน

เปิด `dist/index.html` ในเบราว์เซอร์ได้โดยตรง เนื้อหาและรายงานโหลดจากไฟล์ในโฟลเดอร์เดียวกัน หากเบราว์เซอร์จำกัดการคัดลอกโค้ดหรือการตรวจ hash ในโหมดไฟล์ ให้ใช้เซิร์ฟเวอร์ภายในเครื่องแทน

ถ้ามี Python 3 ให้รันจากโฟลเดอร์นี้:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

เปิด <http://127.0.0.1:4173> หรือใช้ `npm run dev` ถ้ามี Node.js/npm อยู่แล้ว ไม่ต้องติดตั้งแพ็กเกจ

เนื้อหาและส่วนติดต่ออยู่ในเครื่อง อ่านได้โดยไม่ต่ออินเทอร์เน็ต ลิงก์เอกสารต้นฉบับต้องใช้อินเทอร์เน็ต ตำแหน่งอ่านเก็บในเบราว์เซอร์ของเครื่องนั้น

## โครงสร้าง

- `dist/index.html`, `dist/styles.css`, `dist/app.js`: หน้าตาและระบบอ่าน
- `dist/content.js`: เนื้อหาไทยและตัวอย่าง
- `vendor/`: ข้อมูลต้นฉบับและใบอนุญาตตามเวอร์ชันที่อ้างอิง
- `scripts/`: เครื่องมือตรวจสอบ

ตัวอย่างประกอบอธิบายส่วนหนึ่งของแอป เงื่อนไขและข้อจำกัดของตัวอย่างต้องอ่านร่วมกับคำอธิบายในหัวข้อนั้น

## ตรวจซ้ำ

ติดตั้ง Node.js 20 ขึ้นไปและ Rust จากแหล่งทางการ แล้วรัน:

```sh
node scripts/verify.mjs
```

หาก Rust ไม่อยู่ใน PATH ให้ระบุ `RUSTC=/path/to/rustc node scripts/verify.mjs` สคริปต์เทียบสารบัญ ตรวจข้อมูลอ้างอิง และคอมไพล์/รันตัวอย่างในโฟลเดอร์ชั่วคราว ผลอยู่ใน `dist/verification.json` และ `dist/verification.js` สถานะ `blocked`, `failed` หรือ `manual` หมายความว่ายังรับรองผ่านครบไม่ได้ รายงานผูกกับ hash ของไฟล์เนื้อหาและต้องรันใหม่หลังแก้เนื้อหา

การรันโค้ดผ่านไม่ได้พิสูจน์ความถูกต้องของคำอธิบายทุกประโยค ต้องอ่านเทียบเอกสารทางการที่อ้างไว้ด้วย ตัวอย่างคำสั่งหลายไฟล์หรือพึ่งระบบภายนอกต้องตรวจตามหมายเหตุของตัวอย่างนั้น

หากแก้ต้นฉบับเนื้อหาใน `scripts/import-source-content.mjs` หรือไฟล์เรียบเรียงที่สคริปต์นั้นใช้ ให้สร้าง `dist/content.js` ใหม่ก่อนตรวจ:

```sh
node scripts/import-source-content.mjs
node scripts/verify-format.mjs
node scripts/verify.mjs
```

`verify-format.mjs` ตรวจเฉพาะว่าการจัดบรรทัดในรายการตัวอย่างที่ปรับไม่ได้เปลี่ยน token หรือข้อความ literal ไม่ใช่ตัวคอมไพเลอร์ Rust

Rust by Example เป็นผลงานของผู้ร่วมพัฒนา Rust by Example และเผยแพร่ภายใต้ MIT หรือ Apache-2.0 ดูต้นฉบับที่ <https://github.com/rust-lang/rust-by-example> และไฟล์ใบอนุญาตใน `vendor/`
